# Mesh Line

将一条只有位置信息（无宽度）的一维折线Polyline转化为一个具有固定或可变宽度的二维闭合多边形（带状区域）。

带状化Stripping，或折线的缓冲区生成Buffer Generation.

## 核心原理

将一个折线展开为等宽带状集合，最标准的算法是**平行线平移法（角分线法、圆形端点法）**，其步骤如下

- 分段处理：将折线的每一段分别向左右两侧平移（偏移）半个带宽度的距离，生成两条平行的边线
- 拐角（Joint）处里（关键步骤）
    - 尖角连接（Miter Joint）：将相邻两条偏移线的交点作为外角点，能保持折角尖锐，但夹角过小时会产生过长的尖刺，需要设置裁切阈值Miter Limit
    - 圆角连接（Round Joint）：在外角处用圆弧（贝塞尔曲线或正多边形拟合）过渡，视觉效果平滑。
    - 平角连接（Bevel Joint）：直接将尖角顶部截断，形成倒角。
- 端点（Cap）封口：
    - 平头端点（Butt Cap）：在线段终点垂直截断，线条长度不变
        - 当两线夹角不是180°时，外部边缘会形成尖锐的**缺口（Gap）**，
        - 在绘制半透明线条、描边时会露出背景色，视觉很明显，突兀的效果
    - 圆头端点（Round Cap）：以终点为圆心，带宽为直径画半圆，线条长度增加一个线宽
        - 两条线夹角以任意角度相交，圆形端点重叠，不会产生缝隙
        - 视觉平滑，无论任何线条转弯，末端都是圆润的，符合直觉上的毛笔、画笔等写字的效果
    - 方头端点（square Cap）：延申半个带宽后再垂直截断，线条长度增加一个线宽
        - 与平头一样，是需要严格对齐或精确的几何尺寸，不允许有多余的圆弧
- 如果折线复杂或自相交，会造成大量的拓扑错误
    - 自相交（Self-intersection）：当折线急转弯（转角小于60°）时，两侧偏移线会在内部交叉，形成**蝴蝶结**状的无效多边形
        - 进行布尔运算（Union），将交叉的环合并
        - 采样回旋曲线（Clothoid曲线）进行平滑过渡
    - 宽度渐变（可变宽度）：如果折线两端厚度不同（如锥型带状），不能简单平移，必须根据每个顶点处的前后宽度差，计算非对称的加权偏移量

### 定义

在数学上，欧氏几何下，所有到原始折线距离小于等于W/2的点构成的**闵可夫斯基和（Minkowski Sum）**。

在计算机图形学中，有关网格（Mesh）的渲染来打破线条宽度的限制，此时**带状集合**是指定宽度的**三角带（Triangle Strip）**。通常需要将顶点法线（垂直于线段方向）与折线前进方向（切线）构成的具备坐标系，生成一系列矩形条带并拆分为三角形。

- C++，CGAL或Boost.Geometry
- Javascript，Turf.js,处理GIS数据，特别是GeoJSON的数据

折线带状化（Polyline Tessellation）的发展史，本质上是一部在渲染质量、计算效率、算法鲁棒性和样式丰富性之间不断权衡与突破的历史。它也清晰地展现了一个趋势：问题的解决重心，正从早期的CPU几何算法，逐渐向GPU图形管线迁移。
